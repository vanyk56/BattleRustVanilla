## 1. Обзор сборки сервера

В репозитории содержится готовый комплекс из **7 C# плагинов** для игрового сервера Rust:

| Файл плагина | Версия | Автор | Основное назначение |
|---|:---:|:---:|---|
| **`BattleRustWelcome.cs`** | `4.0.0` | Battle Rust | Приветственное окно при входе, GUI меню сервера (`/menu`), вкладки информации, правил, ссылок и K/D статистики. |
| **`GlassReportCheck.cs`** | `1.4.0` | OpenAI | Glass-UI система репортов, вызов на проверку с заморозкой и бессмертием, отправка Discord, выдача модерки, префикс в чате, система вердиктов и банов. |
| **`PopCommand.cs`** | `1.0.0` | You | Просмотр онлайна, спящих, заходящих и очереди игроков через `/pop` и `!pop`. |
| **`ServerRates.cs`** | `1.0.0` | Server | Единые рейты x2: добыча ресурсов, сбор с земли, карьеры, экскаватор, скрап и компоненты в ящиках/бочках. |
| **`SmeltingRate.cs`** | `1.1.0` | OpenAI | Ускорение времени переплавки в печах и работы переработчиков через Harmony-патчи. |
| **`ConfigurableStacks.cs`** | `1.0.0` | Codex | Настройка увеличенных размеров стаков (по умолчанию множитель x2 на стакаемые предметы). |
| **`Vanish.cs`** | `Universal` | Wulf / Oxide | Полная невидимость для администрации, просмотр чужих инвентарей, обход кодовых замков, noclip и телепортация. |

## 2. Сводная таблица всех команд

### Команды для обычных игроков

| Чат-команда | Консоль / Алиас | Описание |
|---|---|---|
| `/welcome` | — | Повторно открыть вступительное окно приветствия (Intro) с логотипом сервера. |
| `/menu` (или `/meu`) | — | Открыть главное меню сервера со вкладками (О сервере, Онлайн, Ссылки, Вайпы). |
| `/info` | — | Открыть сразу вкладку «ИНФО» в меню сервера (рейты, стаки, особенности). |
| `/rules` | — | Открыть окно с правилами сервера. |
| `/pop` | `pop`, `!pop` | Показать текущую популяцию: онлайн игроков, число спящих, загружающихся и очередь. |
| `/report` | — | Открыть интерактивное меню подачи жалобы на подозрительного игрока. |

### Команды для модераторов и администраторов

| Чат-команда | Требуемые права | Описание |
|---|:---:|---|
| `/moder` | `glassreport.moderator` или `IsAdmin` | Открыть быструю панель модератора (тумблер Vanish, переход в меню жалоб). |
| `/modergive <ник\|SteamID>` | `IsAdmin` (администратор) | Выдать статус модератора и право `glassreport.moderator` игроку. |
| `/moderremove <ник\|SteamID>` | `IsAdmin` (администратор) | Забрать статус модератора у игрока. |
| `/check <ник\|SteamID>` | `glassreport.moderator` или `IsAdmin` | Вызвать игрока на проверку (заморозка, бессмертие, звуковой сигнал, экран ввода Discord). |
| `/checkend <ник\|SteamID>` | `glassreport.moderator` или `IsAdmin` | Завершить проверку игрока и открыть окно вынесения вердикта (Чист, Макросы, Читы, Своя причина). |

| `/vanish` | `vanish.allow` | Включить или выключить режим невидимости. |
| `/vanish <true\|false>` | `vanish.allow` | Принудительно включить (`true`) или выключить (`false`) режим невидимки (удобно для биндов). |
| `/inv` | `vanish.invviewer` | Осмотреть инвентарь игрока, на которого смотрит модератор (дистанция до 5 метров). |
| `/inv <ник\|SteamID>` | `vanish.invviewer` | Дистанционно открыть инвентарь игрока (работает как с живыми, так и со спящими). |
| `/invspy` | `vanish.invviewer` | Синоним команды `/inv`. |
| `/debug.invis` / `/invis` | `vanish.allow` | Перенаправляет на команду `/vanish`. |

## 3. Сводная таблица всех прав (Permissions)

Права выдаются через стандартную систему Oxide:  
`oxide.grant user <ник|steamid> <permission>`  
`oxide.grant group <group> <permission>`

| Право (Permission) | Плагин | Описание возможностей |
|---|:---:|---|
| `glassreport.moderator` | **GlassReportCheck** | Доступ к панели модератора `/moder`, вызову на проверку `/check`, завершению `/checkend`, вкладке «Модерация» в `/report`, префиксу `[Moderator]` в глобальном чате. |
| `smeltingrate.admin` | **SmeltingRate** | Доступ к чат-команде `/smeltingrate` и консольной команде `smeltingrate.set`. |
| `vanish.allow` | **Vanish** | Базовое разрешение использовать команду `/vanish` для входа в скрытность. |
| `vanish.invviewer` | **Vanish** | Разрешение осматривать инвентарь других игроков командами `/inv` и `/invspy`. |
| `vanish.unlock` | **Vanish** | Возможность открывать чужие запертые двери, ящики и кодовые замки в режиме невидимости. |
| `vanish.damage` | **Vanish** | Возможность наносить урон игрокам/постройкам в невидимости (при включении хука в конфиге). |
| `vanish.permanent` | **Vanish** | Постоянный режим невидимости (игрок всегда невидим и не может случайно выйти из ваниша). |
| `vanish.teleport` | **Vanish** | Телепортация по карте: создание маркера на карте с зажатой клавишей `R` (Reload). |

## 4. Детальный разбор плагинов

### 1. BattleRustWelcome.cs

* **Назначение:** Приветствие игроков и многофункциональное меню сервера с эстетичным стеклянным оформлением (Glassmorphism).
* **Встроенный арт:** В тело C#-файла встроен сжатый Base64-код логотипа сервера высокого разрешения, загружаемый в хранилище изображений игры (`FileStorage.server`).
* **Разделы меню:**
  1. `main` (Главная) — карточка «О СЕРВЕРЕ», карточка ссылок (Discord, Telegram), блок «СЛЕДУЮЩИЙ ВАЙП» и статус онлайна.
  2. `info` (Информация) — список параметров сервера (тип сервера, рейты x2, стаки x2).
  3. `stats` (Статистика) — топ игроков по Убийствам, Смертям и соотношению K/D (автоматически собирается хуками `OnEntityDeath`).
  4. `rules` (Правила) — свод правил сервера (пункты о запрете читов, багоюза, правила общения и обжалования наказаний).
* **Конфигурация (`oxide/config/BattleRustWelcome.json`):**
  - `ShowOnJoin`: показывать ли меню автоматически при подключении к серверу.
  - `ServerName`, `WelcomeTitle`, `WelcomeLines`: заголовки и текст вступительного окна.
  - `ResetStatsOnWipe`: сброс статистики при вайпе карты (`SaveCreated`).
  - `Links`: список названий, URL и описаний соцсетей.
  - `Rules`: настраиваемый массив строк правил.
  - `UI`: палитра цветов фона, стекла, рамок и текста.
* **Файл данных:** `oxide/data/BattleRustWelcome_Stats.json`.

### 2. GlassReportCheck.cs

* **Назначение:** Комплексная система модерации, обработки жалоб и вызова на проверку.
* **Механика вызова на проверку (`/check`):**
  - Проверяемый игрок полностью замораживается: блокируются тики перемещения (`OnPlayerTick`), позиция циклично пересинхронизируется таймером.
  - Игрок получает полный иммунитет к урону (`OnEntityTakeDamage`), исключая смерть во время проверки.
  - На экран выводится интерфейс с затемнением, таймером проверки и полем для ввода Discord.
  - Проигрывается звуковой сигнал вызова (`assets/bundled/prefabs/fx/invite_notice.prefab`).
  - При отправке Discord модератор мгновенно получает звуковое оповещение и кнопку копирования Discord в буфер обмена. Повторный ввод блокируется во избежание спама.
  - **Защита от лива:** Если проверяемый выходит из игры, модератор немедленно получает алерт в чат. Если игрок перезаходит, плагин автоматически возвращает его на место проверки и вновь блокирует экран.
* **Вердикты проверки (`/checkend`):**
  - **ЧИСТ:** проверка снимается, в чат отправляется объявление, игроку выдается статус «ПРОВЕРЕН» (зеленая плашка в меню репортов на 18 часов, защищающая от повторных необоснованных проверок).
  - **МАКРОСЫ:** выбор срока бана (от 1 дня до перманентного).
  - **ЧИТЫ:** перманентный бан через команду сервера `banid`.
  - **СВОЯ ПРИЧИНА:** ввод кастомного описания и срока блокировки.
* **Префикс в чате:** Игроки с правом `glassreport.moderator` получают оранжевый префикс `[Moderator]` перед ником в общем чате.
* **Встроенный Vanish:** Плагин имеет собственный алгоритм скрытия модератора от сетевых пакетов подписчиков, если отдельный плагин `Vanish` не установлен.
* **Файл данных:** `oxide/data/GlassReportCheck.json`.

### 3. PopCommand.cs

* **Назначение:** Быстрый вывод информации о заполнении сервера.
* **Отображаемые данные:**
  - `Онлайн` (`BasePlayer.activePlayerList.Count`);
  - `Заходят` (`ServerMgr.Instance.connectionQueue.Joining`);
  - `В очереди` (`ServerMgr.Instance.connectionQueue.Queued`);
  - `Спят` (`BasePlayer.sleepingPlayerList.Count`).
* **Особенность:** Перехватывает сообщения `!pop` в чате без спама в глобальный канал (`OnPlayerChat`).
* **Локализация:** Поддержка русского и английского языков в `oxide/lang/ru/PopCommand.json`.

---

### 4. ServerRates.cs

* **Назначение:** Глобальная настройка рейтов сервера с поддержкой вероятностного (стохастического) округления для честной работы дробных рейтов.
* **Настраиваемые категории:**
  - `DefaultRate` (`2.0x`): добыча руды, дерева, камня, серы, металла, ткани инструментами.
  - `PickupRate` (`2.0x`): сбор камней, руды, дерева и конопли с земли.
  - `QuarryRate` (`2.0x`): добыча в карьерах.
  - `ExcavatorRate` (`2.0x`): добыча на Гигантском Экскаваторе.
  - `AnimalRate` (`1.0x`): добыча с туш животных (жир, кожа, мясо, кости).
  - `FishRate` (`1.0x`): вылов рыбы.
  - `ItemOverrides`: индивидуальные множители (например, сера `"sulfur.ore": 2.0`).
  - `LootSettings`:
    - `ScrapRate` (`2.0x`): металлолом в бочках и ящиках.
    - `ComponentRate` (`2.0x`): компоненты (шестеренки, трубы, пружины, корпуса, дорожные знаки, компьютеры наведения и др.).

### 5. SmeltingRate.cs

* **Назначение:** Высокопроизводительное масштабирование скорости переплавки печей и времени работы переработчиков через библиотеку Harmony.
* **Особенности:**
  - Не создает спамящих таймеров — напрямую перехватывает методы печей и переработчиков.
  - Точный расчет дробных тиков (speed 1.5, 2.0, 2.5 и т.д.).
  - Отдельные множители на выход продукции (`OutputMultiplier`), расход топлива (`FuelConsumptionMultiplier`) и генерацию угля (`CharcoalMultiplier`).
  - Возможность мгновенно изменить скорость в реальном времени командой `/smeltingrate <скорость>`.

---

### 6. ConfigurableStacks.cs

* **Назначение:** Увеличение размеров стаков предметов.
* **Особенности:**
  - Глобальный множитель `GlobalMultiplier: 2` (все стандартные ресурсы стакаются в 2 раза больше).
  - Автоматически не затрагивает предметы с прочностью (оружие, броню, инструменты) и не стакаемые вещи.
  - Исключения из коробки: вода (`water`, `water.salt`).
  - Восстановление оригинальных стаков при выгрузке плагина.

---

### 7. Vanish.cs

* **Назначение:** Админский плагин полной невидимости.
* **Возможности:**
  - Полное исключение игрока из сетевой рассылки клиентам (невидим для обычных игроков и читов ESP).
  - Отключение коллизий (можно проходить сквозь игроков и объекты).
  - Автоматическое включение режима полета (`noclip`).
  - Заморозка метаболизма (не требуется еда, вода, не наносится урон от холода/радиации).
  - Осмотр чужих инвентарей через `/inv` (можно просматривать и перекладывать вещи как у живых, так и у спящих игроков).
  - Обход кодовых замков (`vanish.unlock`).
  - Телепортация кликом по карте при зажатой клавише `R`.

## 5. Инструкция по установке и настройке

1. **Установка плагинов:**
   Скопируйте все `.cs` файлы репозитория в папку вашего сервера:
   `oxide/plugins/` (или `carbon/plugins/`).
2. **Первоначальный запуск:**
   Сервер автоматически скомпилирует плагины и создаст файлы конфигурации в `oxide/config/`.
3. **Выдача прав администраторам и модераторам:**
   ```bash
   # Выдача прав модератора системы репортов и проверок:
   oxide.grant user <SteamID> glassreport.moderator
   # Либо прямо в игре администратором:
   /modergive <ник или SteamID>

   # Выдача прав на скрытность (Vanish):
   oxide.grant user <SteamID> vanish.allow
   oxide.grant user <SteamID> vanish.invviewer
   oxide.grant user <SteamID> vanish.unlock

   # Выдача прав на управление скоростью переплавки:
   oxide.grant user <SteamID> smeltingrate.admin
   ```
4. **Рекомендуемые бинды для модераторов:**
   ```
   bind v "vanish"
   bind m "chat.say /moder"
   bind k "chat.say /checkend"
   ```
